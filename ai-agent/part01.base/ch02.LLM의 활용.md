# LLM 활용의 다양한 예시와 그 원리
파인튜닝은 LLM의 사고방식이나 말투를 바꾸기 위해 수행한다.

캐릭터챗의 특성은 '재미'가 중요해서 파인튜닝을 활용한다.

## 사내 지식 챗봇의 Basic 서비스가 된 RAG와 Agent
기업과 자사 맥락과 문서를 학습한 LLM 서비스를 위해 RAG 기반 챗봇을 도입.
문서를 수치화하고, LLM에 잘 전달하는 것.
- Document Processing, Embedding, Retrieval, Reranking, LLMOps 등 여러 요소가 조화롭게 구성
RAG 시스템은 사실 AI 에이전트 서비스의 한 요소일 뿐이다. AI는 Reasoning과 function calling 능력을 바탕으로 복잡한 문제를 작은 단위로 쪼개고, 다양한 도구를 활용하여 지능적으로 처리할 수 있게 되었다.
많은 기업이 AI Agent를 도입 중.

## 실리콘 밸리의 트랜드, 장기 작업 수행이 가능한 AI 에이전트
AI 에이전트는 멀티모달과 컨텍스트 엔지니어링, 멀티 에이전트 아키텍처를 기반으로 사용자의 복잡한 명령을 자율적으로 처리할 수 있는 방향으로 발전되고 있다. 특히 실리콘밸리의 많은 기업은 LLMd의 Reasoning(깊게 생각하는) 능력에 기초하여 Planning 기반 Agent 서비스를 앞세우고 있다.
클로드 코드나 코덱스와 같은 AI 에이전트 서비스는 Code-execution을 통해 실질적인 변화를 만들어낼 수 있는 작동 방식을 갖추고 있다. 외부 API 활용을 넘어 파일을 Read/Write 기능을 통해 더 복잡한 수행을 할 수 있다.

## 웹 브라우저 작업의 자동화, Browser Agent
AI 에이전트는 결국 받아들이는 정보의 품질과 양에 따라서 작업 가능한 범위가 정해진다. 모든 작업이 API 기반의 깔끔한 정보 활용에 기반하지 않기 때문에 Chrome이나 엣지와 같은 브라우저 작업을 대신할 Agent가 개발되고 있다.
